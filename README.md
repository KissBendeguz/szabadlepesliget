# Szabadlépés Liget

A modern static website created for a small business to provide a clean and accessible online presence.

The goal of the project was to build a lightweight, responsive, and easy-to-navigate website that presents the business and its services in a simple and visually appealing way.

## About the Project

This website was developed as a real-world project for a small business.

Since the website mainly serves informational purposes, it was implemented as a static website, keeping the application fast, simple, and easy to maintain.

The project focuses on:

- Clean and responsive design
- Simple navigation
- Fast page loading
- Mobile-friendly layout
- Clear presentation of the business and its services
- Lightweight static architecture

## Technologies

- **Astro**
- **TypeScript**
- **HTML**
- **CSS**
- **Node.js / npm**

## Project Structure


## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/KissBendeguz/szabadlepesliget.git
```

Navigate to the project directory:

```bash
cd szabadlepesliget
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available at:

```text
http://localhost:4321
```

## Production Build

To create a production build:

```bash
npm run build
```

The generated static website will be placed in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
